감성편지 1.4 설치 안내

1) GitHub 저장소(gamseong-letter)에 아래 파일을 같은 폴더(root)에 업로드하세요.

필수 파일
- index.html
- og-preview.png
- bg-night.jpg
- bg-sunset.jpg
- bg-sea.jpg
- bg-forest.jpg
- bg-flower.jpg
- bg-winter.jpg

배경음악 파일(Suno에서 생성 후 업로드)
- bgm-night.mp3   : 별빛 편지
- bgm-sunset.mp3 : 따뜻한 오후의 편지
- bgm-sea.mp3    : 파도처럼 머무는 마음
- bgm-calm.mp3   : 고요한 마음

2) GitHub Pages 주소 예시
https://monggu2785.github.io/gamseong-letter/

3) 주요 기능
- 6개 수채화 배경 썸네일 선택
- Suno 배경음악 4곡 선택
- 배경에 맞는 음악 추천 선택 버튼
- 음악 미리듣기 / 멈춤
- 편지 미리보기
- 짧은 링크 만들기(TinyURL)
- 카카오톡 공유 문구 복사
- 편지 내용 초기화
- 받는 사람 화면에서 편지 자동 스크롤, 일시정지, 음소거, 다시보기

4) 주의
- MP3 파일이 없으면 앱이 비슷한 분위기의 간단한 내장음으로 대체합니다.
- 편지 내용은 URL 해시(#letter=...)에 담겨 전달됩니다.
- 서버 저장은 하지 않지만, Base64는 암호화가 아닙니다.
