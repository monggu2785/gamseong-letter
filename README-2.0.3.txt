감성편지 2.0.3 — 카카오 수신자 홈 화면 추가 흐름 개선

[핵심 변경]
1. 편지 마지막 화면에 3개 버튼 추가
   - ↻ 편지 다시 보기
   - ✍️ 나도 감성편지 보내기
   - 📱 홈 화면에 감성편지 두기

2. 카카오톡에서 홈 화면에 두기 안내 개선
   - 갤럭시 기준: 카카오톡 화면 아래쪽 ⋮ → 다른 브라우저로 열기
   - 삼성 인터넷 권장
   - 삼성 인터넷 아래쪽 ≡ → 현재 페이지 추가(또는 페이지 추가) → 홈 화면

3. 중요한 안전장치
   - 받은 편지의 긴/개별 주소를 홈 화면에 추가하지 않도록
     '홈 화면에 감성편지 두기'를 누르면 먼저 감성편지 기본 홈으로 이동합니다.
   - 카카오톡에서 ?homehelp=1 안내 상태를 유지하여 '다른 브라우저로 열기' 뒤에도 안내가 이어집니다.
   - 삼성 인터넷 등 외부 브라우저로 넘어오면 주소를 감성편지 기본 주소로 정리한 뒤 홈 화면 추가를 안내합니다.

4. 미리보기 마지막 화면은 별도 처리
   - ↻ 미리보기 다시 보기
   - ✍️ 편집으로 돌아가기
