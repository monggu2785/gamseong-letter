감성편지 1.1 설치 방법
=====================

1. GitHub 저장소 monggu2785/gamseong-letter 를 엽니다.
2. 기존 index.html을 이 폴더의 index.html로 교체합니다.
3. og-preview.png도 같은 저장소 루트에 올립니다.
4. 직접 사진 배경을 쓰려면 bg.jpg를 같은 위치에 올립니다.
5. 실제 배경음악을 쓰려면 bgm.mp3를 같은 위치에 올립니다.
6. GitHub Pages가 이미 활성화되어 있으면 잠시 뒤 자동 반영됩니다.

사용 흐름
---------
- 편지 작성
- 배경/음악/속도 선택
- 미리보기
- '짧은 링크 만들기' 클릭
- TinyURL 생성
- '편지 공유하기' 또는 '카톡 문구 복사'

주의
----
- TinyURL 생성은 http/https로 배포된 페이지에서 테스트하세요. file:// 로 직접 연 HTML은 공유 링크용으로 적합하지 않습니다.
- TinyURL이 실패하면 긴 원본 주소가 자동으로 표시됩니다.
- Base64는 암호화가 아닙니다. 아주 민감한 편지는 다음 버전의 ID 저장형(DB 방식)을 권장합니다.
- 카카오톡 미리보기의 제목/이미지는 정적 OG 태그를 사용하므로 편지마다 받는 사람 이름이 미리보기에서 바뀌지는 않습니다.
