[핵심 수정]
1. 편지 내용을 전송 직전에 GZIP으로 자동 압축

   - 지원하지 않으면 기존 Base64 URL(b.)로 자동 전환
2. 기존 1.8 이하 편지 링크도 계속 열 수 있도록 호환 유지
3. 카카오 피드 템플릿에서 동일한 긴 URL을 버튼에 다시 넣지 않음
   - content.link 하나만 전달
   - buttonTitle로 '💌 편지 열어보기' 표시
4. 편지 글자 수 표시 추가
5. 미리보기 임시 보관, 앱 배포 공유, 이메일, 기타 공유, 링크 복사 등 기존 1.8 기능 유지
