감성편지 2.0.1 — 홈 화면 바로가기 안내 개선

[변경 내용]
1. 첫 화면의 “감성편지 설치하기”를 제거했습니다.
2. 대신 “📱 홈 화면에 추가하는 방법”으로 변경했습니다.
3. 갤럭시에서는 삼성 인터넷을 우선 권장합니다.
4. 카카오톡 안에서 열었을 때는 “다른 브라우저로 열기 → 삼성 인터넷” 순서로 안내합니다.
5. Chrome에서 홈 화면 추가가 잘 되지 않는 경우 삼성 인터넷을 이용하도록 안내합니다.
6. PWA 기반(manifest/service worker)은 그대로 유지하여 기존 기능과 업데이트 구조는 보존합니다.

[GitHub에 교체할 파일]
- index.html
- sw.js

manifest.webmanifest 및 아이콘, 배경이미지는 기존 2.0 파일을 그대로 사용해도 됩니다.

[권장 갤럭시 안내]
삼성 인터넷 → 감성편지 열기 → ≡ 메뉴 → 현재 페이지 추가(또는 페이지 추가) → 홈 화면

※ 메뉴 이름은 삼성 인터넷 버전에 따라 조금 다를 수 있습니다.
